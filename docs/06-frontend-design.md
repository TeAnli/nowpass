# 前端界面设计规范

> 实施约定：Vite + React + TypeScript + Ant Design 5 + TanStack Query + Zustand + pnpm。本文是 `frontend/` 的视觉与交互依据，与 `docs/04-api.md` 的接口契约配套。

## 1. 设计方向

**暖纸色阅读界面 × 深青操作色 × 苔绿答案附页。**

- 用户端的关键词是「先思考，再揭晓」，不是题库后台的缩小版。
- 管理端沿用同一套语义 token，但更高密度、更少装饰。
- 核心记忆点：点击「查看标准答案」后，右侧像翻开附页一样展开答案；移动端从底部展开。
- 不做：紫色渐变、玻璃拟态、卡片套卡片、无意义大数字、营销落地页、答案剧透。

## 2. Token 与 AntD 映射

`frontend/src/styles/tokens.css` 分三层：

1. **Primitive**：色板、字体、间距、圆角、时长、阴影、层级。
2. **Semantic**：`--color-bg/text/primary/accent/danger/...`，深色主题只覆盖这一层及必要的组件层。
3. **Component**：按钮、输入框、卡片、题目卡、答案附页、导航、代码块、骨架屏。

| 设计变量 | AntD token / 用法 |
|---|---|
| `--color-primary` | `token.colorPrimary` |
| `--color-text` | `token.colorText` |
| `--color-bg` | `token.colorBgLayout` |
| `--color-surface` | `token.colorBgContainer` |
| `--color-border` | `token.colorBorder` |
| `--radius-md` | `token.borderRadius` |
| `--font-ui` | `token.fontFamily` |
| `--color-danger` | `token.colorError` |
| `--color-warning` | `token.colorWarning` |

原生 AntD 负责表单、表格、分页、弹窗、菜单、加载反馈；自定义 CSS 负责阅读排版、页头、题目条目、答案附页和品牌。不要通过全局覆盖所有 `.ant-*` 样式制造第二套组件库。

## 3. 页面结构

### 公开页

| 页面 | 关键交互 |
|---|---|
| 登录 | 用户名/密码/图形验证码；验证码可点击刷新；621/622/623/624 分开提示；612 自动换图 |
| 注册 | 邮箱先发码（弹窗图形验证码）→ 输入邮箱验证码 → 注册成功明确「等待管理员审批」 |
| 找回密码 | 同样先弹窗图形验证码发码，再输入邮件码和新密码；成功后回登录 |

### 用户端

| 页面 | 关键交互 |
|---|---|
| 题库列表 | 分类、难度、标签、关键词筛选与分页写 URL；返回与刷新保留状态；空态可清空筛选 |
| 题目详情 | 题干与选项先显示，选项不判分；点击答案按钮后才请求答案接口 |
| 个人中心 | 修改昵称与密码分组；改密后提示全部会话失效并回登录 |

### 管理端

| 页面 | 关键交互 |
|---|---|
| 题目 | 表格/移动记录卡 + 抽屉编辑；编辑/预览 Markdown；选择题选项与答案键成对校验 |
| 分类 | 新建、重命名、排序；有题分类禁止删除并显示剩余题数 |
| 用户 | 待审批 Tab、审批、启停、改角色、重置密码；危险动作确认，禁用删自己/超管 |
| 在线会话 | 设备、IP、登录/过期时间、强退；token 只展示，不复制到日志 |
| 操作日志 | 状态/操作人筛选，失败记录可展开错误摘要 |

## 4. 组件状态

### 按钮与链接

- 每屏只有一个主操作；次操作使用默认或文字按钮。
- 默认、hover、active、focus-visible、loading、disabled 均有状态；loading 保持原尺寸，不引起布局抖动。
- 删除、强退、停用必须二次确认；禁用需要解释原因，不能只有灰色按钮。

### 表单

- 可见 label；错误就近展示并带修复动作；不用 placeholder 代替 label。
- 用户名/邮箱/验证码关闭 spellcheck；密码提供显示切换与 autocomplete。
- 提交前启用按钮，请求中显示 spinner 并防重复提交。
- 发码按钮显示 60 秒倒计时，弹窗关闭时清理临时验证码状态。

### 题目与答案

- 题目列表是阅读型条目：难度点 + 文本、标题、分类/标签、进入箭头；不做重复厚卡片。
- 难度同时用文本与标记表达，不只用颜色。
- 答案区 `aria-expanded` / `aria-controls` 关联；Esc 收起并恢复焦点。
- 桌面：右侧约 38% 附页；移动：底部抽屉。加载骨架预留空间，避免 CLS。

## 5. 响应式与可访问性

- 断点 375 / 768 / 1024 / 1440；正文最大行宽约 70 字；后台窄屏表格在容器内横向滚动，不撑破页面。
- 点击目标 ≥44px；焦点 2px 外环 + 2px 间隔；不删除 outline。
- 语义按钮与链接、标题层级、跳到主内容、装饰图标隐藏、图标按钮有名称。
- 反馈用 `aria-live="polite"`；动效只动 transform/opacity；尊重 reduced motion。
- 长标题、长标签、Markdown 长代码与空数组均有专门布局，不允许溢出。
- 深色主题分别校验文本、边框、禁用、成功/失败状态的对比度。

## 6. 验收清单

- 登录、注册、找回密码、审批提示等完整链路真实接口通过。
- 列表/详情/答案的接口职责不混淆：列表无长文、详情无答案、答案按需加载。
- 键盘可完成登录、筛选、打开/关闭答案、后台弹窗确认。
- 375px、768px、1440px 布局检查；空/加载/错误/无权限状态检查。
- 深/浅主题对比检查；reduced-motion 检查；URL 返回与刷新状态检查。
- `pnpm build`、Web Interface Guidelines 审查、后端接口联调通过。

## 7. v2 重设计：居中阅读版式与 GSAP 动效

### 布局

- 全局版心放宽：页头/页脚 1320px，业务页 1280px，后台 1280px。
- 题库列表：标题与筛选居中，筛选器独立卡片，题目列表 1080px 宽的单列索引卡。
- 题目详情：题干卡片 1080px 居中，题干与选项限制在 72ch 阅读宽度；**标准答案不再使用右侧栏，改为下方 980px 居中卡片**，与题干同轴。
- 登录/注册：1440px 内的分栏卡片，左侧品牌区、右侧表单区；移动端单列。
- 后台：深墨绿侧边栏 + 1280px 内容区，筛选工具栏统一为卡片。

### 动效

- 路由切换：`RouteMotion` 使用 GSAP `fromTo(autoAlpha, y)`，320–420ms，`power2.out`。
- 题库列表：数据加载后 GSAP stagger 50ms 逐行入场，只动 `opacity/transform`。
- 答案展开：GSAP 从下方 24px 浮入并平滑滚动到答案区，关闭即销毁 tween。
- 微交互：按钮 hover 上浮 1px / active 缩放 0.98，卡片 hover 抬升，表格行操作按钮仅 hover/focus 时显示。
- 顶部导航：不再使用圆角胶囊背景，改为 GSAP 滑动的 2px 墨线与 5px 方形端点；hover 临时跟随目标菜单，离开回到当前路由；窗口变化时重新测量。
- 卡片悬浮：知识卡图标放大 1.08 并轻微旋转、箭头右移；热门题标题下划线从左展开；题目序号 hover 填充主题色；路线阶段图标轻抬。
- `prefers-reduced-motion` 下跳过 GSAP 动画并禁用 CSS 过渡。

### 图标

- 全项目统一使用 Iconify 的 Lucide 图标集，通过 `AppIcon` 组件调用；不再混用 Ant Design Icons。
- 图标只作装饰时 `aria-hidden="true"`；图标按钮必须由父级按钮提供 `aria-label`。

## 8. 路由与题库细节

- 用户端路由：`/` 主页、`/questions` 题库列表、`/videos` 视频讲解库、`/videos/:id` 视频播放、`/topics` 知识标签卡片、`/questions/:id` 题目详情、`/roadmap` 刷题路线、`/interview` AI 面试间、`/profile` 个人中心。
- 视频列表：分类/标签/关键词筛选，桌面三列、平板两列、手机一列，每页 12 条；播放页原生播放器 + 本地进度/倍速。
- AI 面试间：左侧选题与开始/随机题，右侧对话、语音输入、文字输入、回复朗读和计时；语音识别不可用时自动提示改用文字。
- 主页：紧凑编辑部式首屏（标题 + 数据侧栏）、知识点行式索引、热门题与刷题路线窄面板；减少大留白与大圆角卡片。
- 其他用户页：题库页头部左对齐并压缩筛选/列表高度；知识点页为 2 列行式卡片（88px 行高、40px 图标）；路线、视频库、AI 面试、个人中心统一缩小标题、内边距和卡片圆角，阅读详情保留必要留白。
- 知识标签页：只展示分类卡片，不混放题目列表；卡片图标来自数据库 `question_category.icon`。
- 题库列表：只展示筛选与题目，分类通过下拉选择，不再承载知识卡片。
- 筛选支持分类、难度、标签、关键词、排序（最新/最热/最早/标题）、只看收藏。
- 自定义：每页 10/20/50 条、舒展/紧凑密度、标签显隐与收藏均保存在 `localStorage`。
- 刷题路线：七站式路径（语言 → 运行时 → 数据结构与算法 → 数据与网络 → 框架与云原生 → 分布式与安全 → 模拟面试），完成状态保存在本地。
- 热门题：后端按 `view_count` 排序，打开题目详情时累计浏览量。
- 后台分类管理：图标字段使用 AutoComplete，可从预设 Iconify 图标选择，也可输入自定义图标名，并实时预览。
